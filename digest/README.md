# digest

Claude Code のセッション履歴 (`~/.claude/projects/`) を解析し、繰り返しているプロンプトパターンを検出して、スキル/ルール/CLAUDE.md 化の候補を提案するスキル。

「繰り返しに気づいたら外部化する」を記憶頼みでなく機械的に回すためのもの。月1回程度の実行を想定。

## 使い方

```
/digest          # 直近30日
/digest 7d       # 直近7日
/digest 2w       # 直近2週間
```

## 仕組み

数百MBの履歴を Claude が直接読むことはできないため、同梱の `scripts/claude-digest.mjs`(依存ゼロ・Node単一ファイル)が機械集計を担当し、Claude は結果の意味解釈と提案を担当する2段構成。

1. スクリプトがユーザー発話だけを抽出し(「y」「進めて」等の承認は除外)、文字bigramのJaccard類似度でクラスタリングした Markdown レポートを生成
2. Claude がレポートを読み、言い回しが違う同種指示を意味レベルで統合
3. 既存の skills / rules / CLAUDE.md と突き合わせて未対応のパターンだけを候補化
4. スキル / ルール・CLAUDE.md / プラグイン / エージェントに分類して提案し、承認されたものだけ作成

## レポートに含まれるもの

- **スラッシュコマンド使用回数** — 使っていない自作スキルの棚卸しにも使える
- **繰り返し指示** — 「3回以上 × 複数セッション」の指示クラスタ。外部化の第一候補
- **貼り付けられたエラー** — 例外シグネチャの頻度。2回以上あれば原因のドキュメント化を検討

## スクリプト単体でも使える

Claude を介さず頻度データだけ欲しいときは直接実行できる。

```sh
node scripts/claude-digest.mjs --since 30d -o ~/Downloads/claude-digest.md
```

| オプション | 説明 | デフォルト |
|---|---|---|
| `--since 30d` | 集計期間。`12h` / `7d` / `2w` 形式 | `30d` |
| `--project <substr>` | プロジェクト名の部分一致で絞り込み | 全プロジェクト |
| `--min-count N` | 繰り返しと判定する最低回数 | `3` |
| `--top N` | 繰り返し指示の最大表示件数 | `20` |
| `-o file.md` | Markdown をファイルに書き出す | 標準出力 |
| `--all` | 一時プロジェクト(scratchpad等)も含める | 除外 |
