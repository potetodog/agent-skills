# create-testcase

仕様からテストケースを表で洗い出し、ユーザーの承認を得てからテストを実装するスキル。

[Agent Skills](https://agentskills.io/home) 形式のスキルで、`disable-model-invocation: true` を設定しているため、Claudeが自動判断で実行することはなく、`/create-testcase` と明示的に呼び出したときだけ動く。手順・表の書き方の詳細は [SKILL.md](SKILL.md) を参照。

## できること

- 仕様を「正常時に成立する命題」に書き換えてデシジョンテーブルを作り、条件ごとの異常・境界・結果の網羅を機械的にチェックする
- 観点に応じて表の型を使い分ける。条件の成否で分岐するものは「ケース表」、計算・変換は「値表」、状態遷移は「状態遷移表」
- 表をユーザーに見せて承認を取ってから実装するので、誤った仕様がテストに固定されない。不要なケースはIDで指定して除外できる
- ケース名をそのままテスト名にするので、表と実装を突き合わせてレビューしやすい
- PRの説明欄に載せる用のテストケース表を出力できる

## 使い方

```
/create-testcase <仕様>
```

仕様はオプションであるが、コマンドのみでスキルを呼び出してもどの道仕様を求められる。
まとめられた仕様を確認して承認すると、表 → 漏れチェック → 承認 → 実装の順に進む。

例:

```
/create-testcase ツイートを予約投稿できるようにしたい。ログインしていない人や凍結されたアカウントは予約できない。予約日時は未来の日時だけ選べる。本文は1文字以上280文字以内。
```
